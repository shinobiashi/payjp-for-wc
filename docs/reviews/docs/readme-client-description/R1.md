## 指摘
### [R1-1][High][readme.txt:31, docs/wporg/payjp-for-wc-stable-readme-ja.po]
Key Features の「amount changes（金額変更）」に、対応する実装がない。PAY.JP に金額を送るのは決済フローの作成時と返金時だけ。capture は body を空で送り、与信額をそのまま確定する（`class-wc-gateway-payjp-card.php:494-497`、`class-wc-gateway-payjp-paypay.php:242-245`）。注文編集のフックも、金額を更新する API の呼び出しもない。近いのは、WooCommerce Subscriptions の定期金額の変更（`subscription_amount_changes`、`class-wc-gateway-payjp-card.php:56`）だけ。WordPress.org の readme で、実装と食い違う機能を主張することになる。
**修正方針:** クライアントの文面を変えることになるので、扱いをユーザーに確認する（削る / サブスクの金額変更に限定する / そのまま残して実装する）。

### [R1-2][Medium][readme.txt:15-17]
`== Description ==` の直後が `=== What is PAY.JP? ===` で始まっている。WP.org のパーサーは `==` で始まる行（`===` を含む）をセクションの区切りとして扱う。そのため Description が空と判定され、Short Description が Description の先頭段落として補われる（`readme/class-parser.php` の区切り判定と、空の description を short_description で埋める処理）。結果、公開ページの冒頭に、クライアントの文面案にない段落が重複して出る。
**修正方針:** Description 内の 4 つの小見出しを Markdown の `###` に変える。`###` は区切りにならず、`<h3>` になるので msgid も変わらない。

### [R1-3][Medium][readme.txt:29]
サブスク課金は、有料拡張の WooCommerce Subscriptions が有効なときだけ使える（`class-wc-gateway-payjp-card.php:47-63`）。旧 Key Features の「WooCommerce Subscriptions compatible」が消えたため、Description からこの前提が読み取れない。
**修正方針:** クライアントの文面への追記になるので、ユーザーに確認したうえで、Billing types の括弧に「requires the WooCommerce Subscriptions extension」と訳を足す。
